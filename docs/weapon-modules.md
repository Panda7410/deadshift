# 독립 무기 모듈 규칙 — 3차 플레이테스트

UI와 주행은 기존 구조를 유지하고, 무기 계산만 데이터 기반으로 분리했습니다. 정의는 `src/weapons.js`, 명중 처리는 `src/projectiles.js`입니다. 사거리는 월드 단위이며 10단위 ≈ 1m입니다.

## 계층과 비용

각 슬롯에 발사 방식 / 탄환 특성 / 부가 효과를 하나씩 장착합니다. 각 슬롯은 독립 레벨·모듈·용량·조준·재장전 타이머를 가집니다. 같은 부품을 서로 다른 슬롯에 장착하려면 재고를 각각 소비합니다.

| 계층 | 모듈 | 비용 | 레벨 1 기본 효과 |
|---|---|---:|---|
| 발사 | 직선 단발 | 30 | 피해 16, 간격 0.72초, 사거리 440, 1발 |
| 발사 | 고속 연사 | 40 | 피해 8, 간격 0.22초, 사거리 360, 1발 |
| 발사 | 산탄 | 35 | 발당 피해 12, 간격 1.1초, 사거리 270, 5발, 총 확산 약 25.2도 |
| 탄환 | 일반 | 0 | 추가 효과 없음 |
| 탄환 | 관통 | 40 | 추가 1명 관통 (탄환당 총 2명) |
| 탄환 | 도탄 | 35 | 반경 220 안의 미명중 표적으로 최대 2회 튕김 |
| 탄환 | 분열 | 35 | 첫 명중 후 45% 피해 자탄 3개, 자탄 사거리 180 |
| 효과 | 없음 | 0 | 추가 효과 없음 |
| 효과 | 지연 폭발 | 10 | 명중 0.3초 후 반경 65, 탄환 피해 60% |
| 효과 | 감전 | 15 | 표적 0.2초 경직, 반경 110 다른 표적 1명에 35% 피해 |
| 효과 | 감속 | 10 | 2초간 표적 이동 속도 40% 감소 |

단발 + 관통 + 지연 폭발은 80/90입니다. 연사 + 관통 + 감전은 95로 기본 용량을 초과하므로 용량 +15 또는 효과 제거가 필요합니다. 초과 조합 자체를 금지하지 않고 확장하면 허용합니다. 현재 계층당 한 모듈이며 같은 계층의 여러 특성을 한 슬롯에 동시에 쌓는 기능은 없습니다. 대신 슬롯별 다른 조합과 교차 상태 이상을 지원합니다.

무기 레벨 L: 발당 피해는 기본 × (1 + 0.22 × (L-1)), 발사 간격은 기본 / √L. 강화탄이 켜져 있으면 발당 피해 ×1.18. UI는 `compileWeapon` 결과를 반올림해 표시하고, 실제 발사는 원본 수치를 사용합니다. 이미 발사된 탄환은 발사 시점의 피해·효과를 유지합니다. 초당 발사는 방아쇠 회수이며 초당 탄환 = 회수 × 산탄 수입니다. 고정 시간 틱의 오차를 재장전 타이머에 누적 보정해 장기 평균 발사율이 표시와 맞도록 했습니다.

## 사격 방향과 총구

상단은 360도 회전 포탑입니다. 전방은 차체 전방 중심 총 70도, 좌우는 각 측면 중심 총 130도입니다. 산탄 확산의 끝 탄환까지 이 범위 안에 있도록 표적 허용각을 줄입니다. 표적이 슬롯의 사격각 밖이면 쏘지 않습니다. 슬롯 위치는 차량 회전으로 변환하고 총구·탄환·총구 화염·무기 그림이 같은 변환을 사용합니다.

## 명중 순서와 제한

1. 탄환 이동 구간을 따라 가까운 명중부터 처리하며 동일 탄환은 같은 적에게 다시 직격하지 않습니다.
2. 감속 표적에 감전 직격이면 피해 ×1.25. 직접 피해와 원인·슬롯별 기여도를 기록합니다.
3. 선택한 부가 효과를 적용합니다. 감전의 추가 전기 피해는 다른 효과를 재발동하지 않습니다. 서로 다른 직격에서 생긴 전기 피해가 같은 표적에 반복될 수 있는 조합은 허용합니다.
4. 분열이면 자탄 3개를 생성합니다. 자탄은 효과는 이어받지만 관통·도탄·재분열은 하지 않습니다.
5. 관통 횟수가 남으면 비행 유지, 도탄이면 아직 맞히지 않은 가까운 적으로 방향 변경, 그 외 소멸합니다.
6. 예약 폭발은 지연 후 한 번 피해를 주고 시각 효과만 잠시 남습니다. 폭발은 추가 분열·도탄·폭발·명중 효과를 발생시키지 않습니다.

관통 + 지연 폭발은 관통한 각 적 위치에 각각 폭발을 예약합니다. 산탄은 각 탄환이 독립 관통·명중 효과를 가집니다. 연사 + 도탄은 각 탄환이 독립적인 미명중 집합을 가집니다. 분열 + 효과도 허용하므로 자탄 명중에서 추가 폭발 등이 나올 수 있지만 자탄의 재분열은 없습니다. 한 슬롯의 감속을 다른 슬롯의 감전으로 활용할 수 있습니다.

최대 활성 탄환 512, 예약/시각 폭발 64, 틱당 새 폭발 처리 48, 자탄 세대 1, 자탄 수 3. 초과 생성은 생략하거나 다음 틱으로 넘깁니다. 조합을 제거해 성능을 맞추지 않으며 극단적인 밀집 상황에서는 실제 발사량이 제한될 수 있습니다. 모든 하드웨어에서 일정 FPS를 보장한 것은 아닙니다.

## 획득과 교체

레벨업으로 부품을 얻으면 재고에 들어가며 미리보기 화면이 열립니다. 자동 장착하지 않습니다. 각 슬롯에서 확인 전 초안만 바뀝니다. 두 단계 확인 후에만 새 부품·튜닝권·확장권을 소비하고 이전 부품은 소멸합니다. 취소·다른 슬롯 보기·닫기는 실제 무기를 바꾸지 않습니다. 일반탄과 효과 없음은 무료 기본 상태이며, 발사 방식을 비워 일부 슬롯을 사용하지 않는 실험도 가능합니다. 부품 강화는 현재 슬롯 무기 레벨을 통해 묶어서 적용하고, 부품별 독립 등급은 아직 구현하지 않았습니다.

모듈 공학자 유물: 모든 슬롯 용량 +15, 부가 효과 비용 -5 (최소 0). 반사 프리즘: 도탄 횟수 +1. 충격 발전기·사냥꾼 회로는 새 슬롯 무장에도 적용합니다.

## 플레이테스트 원칙

강한 조합·평범한 조합·예능 조합을 모두 허용합니다. 동일 효율로 평준화하지 않습니다. 새 패턴·탄종·효과는 카탈로그, 순수 컴파일러와 개별 명중 동작을 추가하는 방식으로 확장합니다. 처음부터 모든 가능한 신규 행동을 처리하는 범용 엔진을 완성한 것은 아닙니다. 지금의 48개 조합과 4슬롯 조합 전체에 대한 인간 플레이 밸런스는 아직 미검증입니다.
