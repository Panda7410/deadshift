# DEADSHIFT

관성으로 몰고, 충돌로 돌파하는 2D 탑다운 차량 좀비 서바이벌. **현재는 2차 플레이테스트 개선 버전 (Phase 1 + 성장 시스템 일부)**입니다. 전체 로그라이트 완성판은 아닙니다.

## 실행

Windows에서는 압축을 푼 폴더의 `START-WINDOWS.cmd`를 실행하고 브라우저에서 `http://localhost:5173`으로 접속하면 됩니다. 이전 실행 창은 먼저 닫으세요. 런타임에는 npm 설치가 필요 없습니다.

Node.js 24 LTS 권장. 런타임 외부 서비스, API 키, 계정이 필요 없습니다.

```sh
npm ci
npm run dev
```

서버 포트는 기본 5173이며 `PORT`로 변경할 수 있습니다. 데스크톱 Chromium 계열 브라우저와 키보드가 우선 대상입니다. 게임 시작 버튼으로 오디오가 활성화됩니다.

- W / ↑: 가속
- S / ↓: 제동 후 후진
- A D / ← →: 조향 (정지 상태에서는 회전하지 않음)
- Space: 핸드브레이크, 미끄러지며 선회
- Esc: 일시 정지 / 복귀
- E: 열린 탈출 지점 안에서 탈출 / 계속 파밍 선택
- 메뉴: 방향키 / WASD 이동, Enter / Space 선택, Esc 뒤로 (레벨업은 보상 선택 필요)
- 레벨업: 카드 클릭, 키보드 이동·확인, 또는 1 / 2 / 3
- F3: 평균 속도·충돌 감속·처치 종류·피해 원인·무장 기여도 진단 표시

좀비를 충돌 또는 자동 조준 기관총으로 처치하고 노란 경험치를 수집하세요. 레벨업 시 차량을 개조합니다. **180초 후 동쪽 좌표 (4200, 0)에 탈출 지점**이 열립니다. 화면의 화살표를 따라 지점 안에서 **E** 또는 탈출 선택 버튼을 누르세요. 선택창에서 **지금 탈출**해야 성공하며, **계속 파밍하기**를 선택하면 같은 지역에 머무릅니다. 진입만으로 종료되지 않습니다. 오래 머무를수록 생성 주기가 짧아지고 빠른 적과 중장갑 적이 등장합니다. 벽과 잔해 충돌은 감속과 내구도 손상을 일으킵니다. 정차한 채 좀비에 둘러싸이지 마세요.

## 주행 월드 및 충돌 규칙

월드 1단위는 표시 거리 약 0.1m입니다. 월드는 **96,000 × 96,000 단위**, 시작점에서 외곽까지 48,000입니다. 화면은 그중 일부만 보여주며 카메라가 부드럽게 이동하고 속도에 따라 앞을 봅니다. 1,600 단위 간격의 폭 440 도로망이 공터와 건물 구역을 연결합니다. 교차로에서 넓게 회전할 수 있고 모든 도로 중심선은 고정 장애물 없이 연결됩니다. 화면 밖 구역은 결정론적으로 생성됩니다. 건물은 블록 단위, 파괴물은 검문소의 바리케이드 묶음, 물류 구역의 상자·컨테이너, 사고 구간의 폐차·잔해로 구성됩니다. 중앙 주행 차선은 열려 있고 군집은 우회하거나 돌파할 수 있습니다.

- 회녹색 대형 콘크리트 지붕: 고정 건물. 측면은 미끄러지며, 고속 정면충돌은 위험합니다.
- 황갈색 X 표시 상자: 소형 파괴물. 정면 속도 48 이상이면 기본 차량도 안전하게 돌파합니다.
- 금속색 몸체와 황색 띠의 폐차 / 바리케이드: 중형. 기본 차량의 정면 속도 약 165 이상, 또는 충각 / 중량 강화로 돌파합니다.

실제 판정은 단순 접촉이 아니라 **접촉면을 향한 속도**, 중량, 차량 전면 방향 및 충각에 따릅니다. 예를 들어 총속도가 240이어도 벽을 향한 성분이 20이면 피해 없이 스칩니다. 건물 충돌은 법선 방향 속도만 제거하고 접선 방향은 보존하며 반사 튕김은 제거했습니다. 저속 접촉은 위치 보정 위주입니다.

초기 가속 105, 최고 속도 약 170 (계기판 약 61km/h)으로 낮췄습니다. 엔진 1회 강화는 출력 +35%로, 최고 속도 약 206 (약 74km/h)과 가속력 증가를 제공합니다. 가벼운 차량의 저속 조향은 쉬우며 고속에서는 조향과 접지력이 낮아져 미끄러집니다. 무거운 차량은 가속 / 조향 / 제동이 둔해지고 돌파력은 증가합니다. 엔진 강화는 가속과 최고 속도를 함께 높입니다.

도로 직진 시 기본 차량은 120초 동안 약 20,195 단위를 주행해도 외곽까지 27,000 이상 남습니다. 동쪽 탈출 지점 4,200까지의 직선 무전투 주행은 약 25.72초, 엔진 1회 강화는 약 21.22초입니다. 게이트는 180초 이후 개방됩니다. 좀비는 주행 전방 위주의 무리로 생성되어 돌파 기회를 제공합니다. 단일 일반 좀비는 적은 감속으로 처치할 수 있지만, 질량과 접촉면 접근 속도에 따른 운동량 교환으로 연속 충돌은 감속을 누적시킵니다. 중량형 (650kg)은 기본 차량과 충각 1회 강화에도 큰 저항을 주므로 재가속·우회·화력 조합이 필요합니다. 충각 강화는 피해와 저항 극복을 개선하지만 저항을 없애지 않습니다. 정지한 채 포위되면 여전히 위험합니다.

## 구조 및 선택

- `src/core.js`: 브라우저와 독립적인 차량 물리, 충돌, 업그레이드, 저장 포맷
- `src/world.js`: 연결된 도로망, 구역 생성, 장애물 접촉 및 부드러운 카메라
- `src/combat.js`: 적 유형·위협 구성, 장착 위치와 총구 기반 무장, 보급품·유물 상호작용
- `src/menu.js`: 공통 키보드 메뉴 포커스와 입력 분리
- `src/game.js`: 고정 120Hz 시뮬레이션, 렌더링, 전투, 입력 및 화면 상태 전환
- `scripts/`: 의존성 없는 정적 개발 서버와 빌드 도구
- `tests/`: Node 테스트와 Chromium 브라우저 시나리오

자체 Canvas 2D를 선택했습니다. 작은 배포 크기와 단순한 정적 호스팅, 물리 튜닝의 직접 제어가 장점입니다. 엔진의 에디터·충돌 도구·에셋 파이프라인을 직접 구현해야 하는 비용이 있습니다. 게임 런타임은 외부 의존성이 없고 `playwright-core`는 개발 검증에만 사용합니다. 그래픽은 Canvas / 직접 작성한 SVG, 소리는 Web Audio로 생성합니다. 외부 아트·음원·폰트를 사용하지 않습니다.

중량은 가속력과 최고 속도에 영향을 주고 충돌 피해를 높입니다. 기본 차체는 1,200kg이며 충각·장갑·무기는 무게를 더합니다. 같은 장비 선택은 슬롯을 무한 생성하지 않고 그 슬롯을 강화합니다. 지붕 기관총, 좌우 쌍열 기관총, 전방 산탄포를 지원하며, 장착 위치와 회전하는 총구 좌표를 무기 그림·발사·총구 화염에 공통 사용합니다. 측면 무기도 자동 회전 조준하며 고정 사격각 제한은 없습니다. 충각·장갑·엔진을 포함한 일반 강화 외에 충격 발전기 (운동량 손실 → 무장 재장전), 연쇄 점화기 (충돌 처치 → 잠깐 출력 증가), 사냥꾼 회로 (무장 처치 → 충각 강화)를 제공합니다. 유물은 중복 선택지에서 제외됩니다.

## 위험·성장·보급품

처음에는 일반 좀비 무리를 돌파합니다. 30초 이후 추격형 (속도 155), 55초 이후 중량형, 70초 이후 측면 압박, 90초 이후 산성 방사형이 추가되고 군집 수와 생성 빈도가 증가합니다. 130초 이후 원거리 적이 섞인 조합이 늘어납니다. 일반 적의 체력·공격력을 시간에 따라 일괄 증폭하지 않습니다. 산성 원은 약 0.85초의 경고 후 활성화되며, 범위 안에서는 감속과 피해가 발생합니다. 무장 중심 차량도 포위·근접·산성 구역을 피해야 합니다.

필드 아이템은 자동 접촉 획득하며 종류마다 표시와 색이 다릅니다. 일반 처치 5.5%, 중량형·방사형 처치 45%, 파괴물 20% 확률로 4종 중 하나가 생성되어 24초 동안 남습니다.

| 표시 | 아이템 | 효과 |
|---|---|---|
| + / 녹색 | 수리 키트 | 내구도 28 회복 |
| M / 청색 | 자석 | 12초 동안 경험치 흡수 1000, 보급품 흡수 700 범위 |
| F / 황색 | 부스트 연료 | 8초 동안 출력 40% 증가, 가속·최고 속도 개선 |
| S / 보라색 | 방어 보급품 | 10초 동안 받는 피해 55% 감소, 장갑 별도 적용 |

재획득은 남은 시간을 더하지 않고 기본 지속 시간으로 갱신합니다. 수리·시간제 보급품은 런 종료 시 초기화됩니다. 파괴물의 방향성 파편은 3~5초 남아 타이어에 밀리며 최대 240개로 제한합니다.

## 검증

```sh
npm run check
npm test
npm run build
# 다른 터미널에서 프로덕션 서버
node scripts/serve.mjs --dist
npm run test:browser
# 같은 서버가 실행 중일 때: 시드 3개, 빌드 4종의 실제 게임 시뮬레이션
npm run test:balance
```

브라우저 테스트는 `/usr/bin/chromium`을 사용하거나 `CHROMIUM_PATH`를 지정합니다. 없으면 `npx playwright-core install --with-deps chromium`으로 설치합니다. 테스트는 `?test=1`에서만 노출되는 시나리오 API로 충돌·레벨업·사망·탈출 조건을 설정합니다. 실제 키보드 주행과 렌더링도 검증하지만, 자연 플레이 180초 완주 또는 재미·밸런스 검증을 대체하지 않습니다. 추가 브라우저 검사는 정상 적 생성 상태에서 22초간 실제 W 입력 주행, 소형 / 중형 돌파, 건물 정면충돌과 후진 이탈을 확인합니다. Node 검사는 120초 도로 직진, 25개 구역의 접근 가능한 공간 연결성, 충돌 각도와 중량, 카메라 수렴 및 탈출 지점 이동 시간을 확인합니다. 성장 검사는 키보드 전체 흐름·입력 누출 방지·보급품 4종·총구 좌표·장비·잔해·원거리 위협을 확인합니다. 캡처는 `artifacts/phase1-desktop.png`, `artifacts/growth-equipment.png`에 생성됩니다. 빌드 비교는 실제 고정 시간 게임 업데이트에서 직진 W 자동 조작과 정해진 레벨 보상 경로로 수행하고, 무강화는 보상을 건너뜁니다. 같은 시드라도 이동과 처치에 따른 난수 사용이 달라 적 배치는 완전히 같지 않습니다. 결과는 `artifacts/build-comparison.json`이며 인간의 회피·조향과 실제 보상 운을 반영하는 공정한 최종 밸런스 판정은 아닙니다.

## 저장

`localStorage`의 `deadshift.save`, 버전 1에 출격 횟수·최고 생존 시간·누적 처치를 저장합니다. 새로고침 후 유지됩니다. 알 수 없는 버전이나 손상된 데이터는 기본값으로 초기화합니다. 브라우저 개발자 도구에서 해당 키를 삭제하면 기록을 초기화할 수 있습니다. 저장이 막힌 경우 결과 화면에 표시하며 게임은 계속 작동합니다. 런 이어하기, 영구 스킬트리, 저장 내보내기 / 가져오기는 미구현입니다.

## 정적 배포

`npm run build` 결과 `dist/`를 정적 호스팅에 올리세요. 모든 앱 리소스는 상대 경로로 로딩하므로 `/deadshift/` 같은 하위 경로에서도 실행됩니다. Node 서버는 개발 도구이며 배포 시 필요 없습니다.

GitHub Pages 배포 준비:

1. 코드를 GitHub의 `main` 브랜치에 푸시합니다.
2. 저장소 Settings → Pages → Build and deployment의 Source를 **GitHub Actions**로 설정합니다.
3. Actions의 `Validate and deploy DEADSHIFT` 실행이 성공했는지 확인합니다.
4. Pages 화면 또는 배포 작업에 표시되는 실제 URL로 공유합니다.

워크플로는 PR에서 검증만, main에서 검증 후 배포합니다. Pages 권한 및 활성화는 저장소 소유자가 필요할 수 있습니다. 클라우드에서 실제 배포는 아직 수행하지 않았으며 공유 URL이 발급되었다고 주장하지 않습니다.
